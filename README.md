# Orbit

A one-tap arcade game for iOS. A dot circles a glowing planet — tap to release it, fly straight, and get caught by the next planet's orbit. Hit dead-center through the core for a **PERFECT +2**. Miss, and you drift into the void.

Fully offline, zero dependencies, all visuals generated in code (SwiftUI + SpriteKit).

## Play

- **Tap** to launch off your current orbit.
- Get captured by the next ring to score **+1**.
- Aim through the planet's core for **PERFECT +2**.
- Orbits spin faster the further you get. Best score is saved locally.

## Build & run

```sh
brew install xcodegen   # once
xcodegen generate
open Orbit.xcodeproj    # then Cmd+R on a simulator or device
```

The app icon is generated by `swift Tools/make-icon.swift Orbit/Assets.xcassets/AppIcon.appiconset/AppIcon.png`.
